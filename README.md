# Nabiha’s Wonderland

A personal birthday invitation website inspired by *Alice in Wonderland*, with an antique storybook entrance, a journey down the rabbit hole, and an interactive character wardrobe.

[Visit the website](https://naboohaa.github.io/bday-wonderland/)

## Features

- An ivory storybook entrance with gradual lettering, a watercolor-style rabbit hole reveal, and a “Follow me” button.
- An animated falling sequence leading to the birthday invitation.
- An RSVP form with additional questions for guests who cannot attend, submitted through Formspree.
- A wishlist with a linked photocard guide.
- A dress code wardrobe with eight character-inspired outfits and a “Surprise me” option.
- Responsive layouts for desktop and mobile, with reduced-motion support.

## Built with

HTML, CSS, and vanilla JavaScript. Hosted on GitHub Pages, with Formspree handling RSVP submissions.

## Main files

| File or folder | Purpose |
| --- | --- |
| `index.html` | Page content, invitation, forms, and dialogs |
| `style.css` | Main styles and layout |
| `css/` | Additional styles for the theme, storybook, and components |
| `script.js` | Navigation, falling sequence, dialogs, RSVP handling, and outfit selection |
| `storybook.js` | Entrance lettering and image reveal sequence |
| `images/` | Backgrounds, rabbit hole artwork, preview image, and outfit illustrations |
